# NJUPT Club Game - 钩爪物理系统

一个基于 Godot 引擎的 2D 平台跳跃游戏，核心玩法围绕钩爪/抓钩物理系统展开。

## 项目简介

本项目实现了一个钩爪物理系统，玩家可以通过发射钩爪锚定到场景中的墙壁或锚点，利用绳索的拉力进行摆动、跳跃等动作。系统包含真实的物理模拟，支持动态调整绳索长度、绳索碰撞检测等进阶功能。

## 操作说明

| 按键 | 功能 |
|------|------|
| A / D | 左右移动 |
| 鼠标左键 | 发射钩爪 |
| 鼠标右键 | 剪断绳索 |
| 小键盘 + | 收绳（缩短绳索） |
| 小键盘 - | 放绳（伸长绳索） |
| 空格 | 跳跃 |

### 游戏流程
1. 使用鼠标瞄准目标位置（墙壁/锚点）
2. 点击左键发射钩爪
3. 钩爪命中后，玩家会被拉向锚点
4. 利用绳索摆动到达难以直接跳跃的平台
5. 使用小键盘 +/- 调整绳索长度控制摆动幅度
6. 右键剪断绳索恢复自由状态

## 技术选型

### 游戏引擎
- **Godot 4.8** - 现代化的开源游戏引擎，支持 C# 脚本
- **渲染模式** - Forward Plus（高质量渲染管线）

### 编程语言
- **C#** - 强类型语言，适合复杂逻辑和状态管理

### 物理系统
- **RigidBody2D** - 玩家角色使用刚体物理，实现真实的物理交互
- **RayCast2D** - 射线检测，用于钩爪命中判定和绳索碰撞检测
- **自定义物理计算** - 在 `_IntegrateForces` 中实现绳索拉力和摆动效果

### 状态管理
- **CustomFSM（自定义有限状态机）** - 基于异步任务的状态机实现
  - 支持状态转换、事件驱动
  - 使用 `CancellationToken` 管理状态生命周期
  - 支持等待异步事件完成

### 核心架构
```
PlayerController (RigidBody2D)
├── 状态机 (CustomFSM)
│   ├── State_Idle - 待机状态
│   ├── State_Fire - 发射钩爪
│   ├── State_HookIdle - 钩爪已锚定
│   ├── State_Drag - 牵引状态
│   ├── State_Break - 断开绳索
│   └── State_HookJump - 钩爪状态下的跳跃
├── Gun (Node2D)
│   ├── RayCast2D - 射线检测
│   └── 钩爪发射逻辑
└── Hook (Node2D)
    └── Line2D - 绳索视觉渲染
```

## 进阶挑战完成情况

### ✅ 已完成的进阶挑战

#### 1. 摆动物理效果
- **实现方式**：在 `_IntegrateForces` 中计算玩家与锚点的距离
- **物理逻辑**：当距离超过绳索长度时，将玩家位置拉回到以锚点为圆心、绳索长度为半径的圆上
- **效果**：实现了真实的钟摆运动效果

#### 2. 收绳/放绳控制
- **按键映射**：小键盘 +/- 键
- **实现**：动态修改 `hook_length` 变量
- **限制**：绳索长度最小为 0，防止负长度
- **参数**：`LineLenModifierFactor` 控制调整速度

#### 3. 绳索碰撞检测
- **实现方式**：使用 `MoveRayCast` 检测玩家与钩爪之间的障碍物
- **触发条件**：当绳索长度超过 `LineBreakLimit` 阈值时触发检测
- **碰撞处理**：检测到障碍物时自动断开绳索，防止穿墙
- **视觉反馈**：绳索断开时玩家位置修正到碰撞点

### ❌ 未完成的进阶挑战

#### 4. 钩爪轨迹预览线
- **状态**：未实现
- **预期功能**：在发射前显示钩爪的飞行路径
- **实现思路**：可以使用 `Line2D` 绘制预测轨迹，或使用粒子系统

## 配置参数

### PlayerController 参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| Speed | 400.0 | 移动速度 |
| JumpHight | -600.0 | 跳跃高度 |
| LineForceFactor | 0.35 | 绳索拉力系数 |
| LineLenModifierFactor | 10.0 | 绳索长度调整速度 |
| LineBreakLimit | 20.0 | 绳索断裂阈值 |

### Gun 参数
| 参数 | 说明 |
|------|------|
| HookVel | 钩爪飞行速度 |
